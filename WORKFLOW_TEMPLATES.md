# Workflow Templates

## Feature

Inspect -> Requirements -> Scope -> Checkpoint -> Implement -> Test -> Diff -> Docs -> Report.

## Bugfix

Reproduce -> Locate layer -> Test -> Minimal fix -> Regression -> Validate -> Diff -> Report.

## Knowledge

Applicability -> Source -> Provenance -> Review -> Verification -> Validate -> Changelog.

## Migration

Schema analysis -> Target -> Non-destructive migration -> Tests -> Backup -> Validate.

## Release

Requirements -> State -> Build -> Tests -> Knowledge -> UI -> Recovery -> Git -> Release.
