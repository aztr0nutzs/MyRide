# Release Checklist

## Repository

- [ ] Requirements reviewed.
- [ ] Project state synchronized.
- [ ] Known issues reviewed.
- [ ] Git status clean or intentionally documented.
- [ ] No secrets committed.

## Build

- [ ] Correct JDK verified.
- [ ] Gradle wrapper verified.
- [ ] Android SDK verified.
- [ ] Debug build passes.
- [ ] Release build passes if applicable.

## Tests

- [ ] Unit.
- [ ] Persistence.
- [ ] Knowledge.
- [ ] Integration.
- [ ] Critical UI.
- [ ] Accessibility.
- [ ] Regression.

## Data

- [ ] Migration tests pass.
- [ ] Export/import round trip passes.
- [ ] Backup restore passes.

## Automotive knowledge

- [ ] Vehicle-specific claims have provenance.
- [ ] Applicability reviewed.
- [ ] Unknowns are not disguised as facts.
- [ ] Safety-critical entries reviewed.

## UX

- [ ] No dead controls.
- [ ] No cropped instructions.
- [ ] Offline state behaves correctly.
- [ ] Errors are recoverable.

## Final

- [ ] Changelog updated.
- [ ] Version metadata correct.
- [ ] Release commit/checkpoint created.
