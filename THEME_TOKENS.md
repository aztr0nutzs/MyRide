# Theme Tokens

## Naming model

Use semantic tokens rather than scattering raw color values throughout components.

## Surface tokens

- backgroundPrimary
- backgroundSecondary
- surfacePrimary
- surfaceElevated
- surfaceInstrument
- surfaceOverlay

## Accent tokens

- accentPrimary
- accentSecondary
- accentMint
- accentPink
- accentWarning
- accentFault

## Text tokens

- textPrimary
- textSecondary
- textMuted
- textOnAccent
- textError

## Border tokens

- borderSubtle
- borderActive
- borderWarning
- borderFault

## State tokens

- stateVerified
- stateUnknown
- stateWarning
- stateFault
- stateActive
- stateDisabled

## Rule

Components should consume semantic tokens. Theme implementation may change without rewriting feature logic.
