# Antigravity Operating Model

## Startup

The agent should load the project context from repository files rather than relying on chat memory.

Required reading:

1. README.
2. Requirements.
3. State.
4. Architecture.
5. Roadmap.
6. ADRs.
7. Relevant rules.
8. Relevant skill/workflow.

## Plan

Produce a bounded plan for multi-file work.

## Execute

Work in coherent stages.

## Verify

Run focused tests first, then broader validation.

## Review

Inspect the full diff.

## Synchronize

Update state/changelog/docs when implementation status changes.

## Recovery

Checkpoint before risky operations.

Never use a destructive repository reset to hide mistakes.

## Context preservation

If a task cannot be completed because information is missing, document the blocker rather than guessing.
