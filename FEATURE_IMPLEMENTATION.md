# Feature Implementation Prompt

Implement the requested feature as a bounded change.

Required:
- Read project source-of-truth.
- Inspect actual implementation.
- Identify architecture layer.
- Identify requirements and ADRs.
- Preserve behavior outside scope.
- Preserve stable IDs.
- Protect persistence.
- Add/update tests.
- Handle empty/loading/error states.
- Respect visual design.
- Do not invent automotive values.
- Do not add speculative dependencies.

Completion requires validation and diff review.
