# Component Catalog

## Vehicle Status Card

Displays vehicle identity and selected configuration state.

Must visibly distinguish verified and unknown configuration.

## Diagnostic Card

Displays a complaint, current diagnostic state, evidence count, and next action.

## Measurement Panel

Displays value, unit, timestamp, source, and optional comparison.

## Procedure Step

Contains step number, action, warning, completion state, and observation capture.

## Safety Panel

Contains hazard, required condition, and stop action.

## Provenance Indicator

Shows whether information is verified, sourced, user-entered, derived, or unknown.

## Maintenance Timeline

Chronological event list with category and concise summary.

## Checklist Item

Supports incomplete, pass, fail, not-applicable, and notes where relevant.

## Error State

Explains:

- What failed.
- What was preserved.
- What the user can do next.

## Empty State

Explains why the area is empty and provides a real action when one exists.

## Button rules

Every visible action must have a defined behavior.

Never create decorative controls that look actionable.
