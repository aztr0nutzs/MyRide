# Visual Design System

## Creative direction

Dark industrial automotive diagnostic interface inspired by the established NERF/N.E.R.F visual theme.

The application should feel like a rugged digital diagnostic instrument, not a generic consumer dashboard.

## Base

Near-black layered backgrounds.

Avoid pure flat black everywhere. Use subtle surface separation.

## Primary accent

Neon cyan.

Use for:

- Active navigation.
- Technical data.
- Focus.
- Primary action.
- Instrument highlights.

## Secondary accents

- Neon purple.
- Mint green.
- Neon pink.
- Neon yellow-green.

Use secondary colors intentionally.

## Semantic states

VERIFIED: positive/mint family.
WARNING: yellow/yellow-green family.
FAULT: red family.
INFORMATION: cyan family.
UNKNOWN: neutral.
ACTIVE: cyan.
DISABLED: subdued.

Never communicate meaning through color alone.

## Typography

Technical/condensed headings may be used.

Body copy must remain highly legible.

Measurements and diagnostic values receive strong numeric hierarchy.

## Components

- Vehicle status card.
- Diagnostic card.
- Measurement panel.
- Procedure step.
- Safety panel.
- Maintenance timeline item.
- Inspection checklist.
- Primary action.
- Secondary action.
- Navigation item.
- Search result.
- Provenance badge.
- Unknown-state display.
- Empty state.
- Error state.
- Loading state.

## Garage ergonomics

- Large controls.
- High contrast.
- Short labels for actions.
- Long instructions in scrollable panels.
- No content hidden behind fixed heights.
- Clear active/inactive states.

## Accessibility

- Dynamic text support.
- Semantic labels.
- Adequate touch targets.
- Screen-reader order.
- Non-color status communication.
- Focus visibility.

## Motion

Use animation for state communication, not decoration that interferes with task completion.
