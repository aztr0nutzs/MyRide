# Change Control

Every material change answers:

- What?
- Why?
- Requirement?
- Architecture layer?
- ADR?
- Tests?
- Persistence impact?
- Knowledge impact?
- Safety impact?
- Documentation impact?

## Scope expansion

A change that unexpectedly requires unrelated modules, dependencies, schema changes, or architecture changes is a stop-and-review event rather than an invitation for the agent to improvise.
